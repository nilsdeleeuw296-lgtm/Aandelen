Portfolio Planner v6 (light UI)
================================
Start (Windows):
1) Installeer Node.js LTS (als je dit nog niet hebt)
2) Dubbelklik START_WEBSITE.bat
3) Browser opent: http://localhost:5174

Belangrijk:
- Koersen komen via Stooq (primary), Yahoo (fallback) en daarna cache/handmatig.
- Als een ticker geen koers heeft: ga naar Instellingen -> Handmatige prijzen.

Troubleshooting:
- 'node' not recognized: installeer Node.js LTS en herstart.
- 'Not found' op /: zorg dat je http://localhost:5174 gebruikt en niet file://


Nieuw:
- Rebalance: trade-lijst op basis van jouw Eigen portfolio aantallen vs Builder target.
- Dashboard: toont 'Ingelegd', projecties en (optioneel) een lijn uit snapshots van Eigen portfolio.
  Een snapshot wordt automatisch opgeslagen zodra je in Eigen portfolio op 'Opslaan' klikt.
